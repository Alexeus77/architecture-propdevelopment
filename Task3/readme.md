Интеграция с внешней системой оператора смарт-устройств (домофон и шлагбаум) должна отвечать следующим требованиям безопасности:
- передача данных должна проводиться по шифрованным защищенным каналам связи (HTTPS с TLS 1.3)
- вызовы в систему оператора смарт-устройств должны протоколироваться
- вызовы по REST API осуществляются с API-ключом
- информация от внешней системы поступает через Kafka с SSL
- оператор смарт-устройств должен нести ответственность за получение и хранение персональных данных (биометрия) в соответствии с ФЗ-152
- пользователь должен подписать соглашение (в цифровом или бумажном виде) на передачу своей биометрии третьему лицу (оператору смарт-устройств)
