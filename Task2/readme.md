Аудит безопасности начнём с фокусом на выделенные проблемы бизнеса:
1. Повышение уровня удовлетворения клиентов за счёт выявления ошибок ЛК. Необходимо проверить аутентификацию и авторизацию клиентов в системе и выявить причины ошибочного доступа к чужим ЛК.
2. Провести анализ хранения потоков данных и выявить, что мешает использовать эти данные в BI- ML- и AI- систмемах.
3. Принять меры к защите чувствительных данных (прежде всего секретных и конфиденциальных)
4. Проверить систему на соответствие ФЗ

Т.о. в чек-лист аудита безопасности включим разделы "Управление доступом" и "Безопасность данных" из стандартного чек-листа, которые помогут в решении проблем под пунктами 1 и частично 3, 4 и 2. 
Также это поможет для обозначенных проблем с доступом к системам со стороны партнеров, а также использование самой системой API управляющих компаний.

Также добавим пункт о проверке системы на нарушения ФЗ-152 в реализации пункта 4 b xfcnbxyj 2:

- Получено информированное согласие субъектов (цифровое или бумажное), оформленное согласно ФЗ-152.
- Ведётся учёт всех информационных систем, в которых обрабатываются персональные данные
- Разработана и опубликована Политика обработки персональных данных
- Внедрены процедуры по уничтожению/обезличиванию данных
- Реализована процедура отзыва согласия
- Реализовано ограничение доступа к перс данным по ролям RBAC
- Логирование действий с перс данными
- Использование шифрования данных в БД
- Передача перс данных проводится только с использованием защищенных каналов (HTTPS, mTLS)
- Проведен аудит публичных API на предмет экспонирования перс данных
- Перс данные хранятся только на частных серверах
- Реализована процедура анонимизации перс данных для использования их в системах BI, ML и AI
