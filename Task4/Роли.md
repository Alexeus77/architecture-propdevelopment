| Роль  | Права роли | Группы пользователей | 
| cluster-secrets-admin | Управление секретами | secrets-team | 
| cluster-view | Просмотр ресурсов кластера | cluster-viewers |
| cluster-manager | Управление ресурсами кластера, кроме секретов и RBAC | cluster-managers |

Для добавления ролей выполните:

kubectl apply -f .\cluster-manager-role.yml
kubectl apply -f .\cluster-managers-binding.yml
kubectl apply -f .\cluster-viewer-role.yml
kubectl apply -f .\cluster-viewers-binding.yml
kubectl apply -f .\cluster-secrets-admin-role.yml
kubectl apply -f .\cluster-secrets-admins-role-binding.yml
